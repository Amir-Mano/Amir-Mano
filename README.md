# Amir Mano

PhD candidate in neuroscience at Tel Aviv University, in the [Yaniv Assaf Lab](https://yanivassaflab.com/).
I study how music learning shapes the brain, using diffusion MRI, connectomics, and
naturalistic fMRI with custom auditory stimuli. Musicians serve as a model for skill
learning and neuroplasticity. Also an active trombone player.

Portfolio: **[amir-mano.github.io/personal_website](https://amir-mano.github.io/personal_website/)**

### Ask me about
- Music learning & neuroplasticity
- Naturalistic fMRI with custom-designed auditory stimuli
- Diffusion MRI & connectomics (structural and functional brain networks)
- Skill learning as a model for studying brain plasticity
- Trombone performance
